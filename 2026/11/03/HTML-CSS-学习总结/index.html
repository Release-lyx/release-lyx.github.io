HTML & CSS 学习总结

HTML

负责网页结构，搭骨架。

CSS

负责样式，美化页面。

重点（网安方向留意）

  • display:none：元素直接从布局移除，看不见、不占位置
  • visibility:hidden：看不见，但是仍然占据页面空间
  • 复合选择器：后代、子代、交集、并集

权重口诀

id（100）> class（10）> 标签（1）

易错点

  • 权重不是数字直接相加进位，是从左往右依次比较
  • background-image 背景图，和 <img> 图片标签用途不一样
